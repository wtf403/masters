Для выбора темы ВКР (диплома) вам нужно:
- определиться с тематикой / придумать несколько идей - тема должна соответствовать вашему направлению и профилю;
- связаться с потенциальным дипломным руководителем и договориться о руководстве (сразу пишите, какие темы или идеи у вас есть);
- сформулировать окончательную тему диплома;
- скачать бланк заявления;
- заполнить заявление, добавить свою подпись и выслать своему руководителю в формате .docx.

После этого руководитель согласует заявление и высылает на кафедру.
